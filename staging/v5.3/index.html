What the extension does

  • Connect and explore

    Connect to Azure or any PostgreSQL server, then browse schemas and tables.

  • Schema-aware IntelliSense

    Table and column names complete from your live database as you type.

  • Ask @pgsql

    Ask about your data in GitHub Copilot Chat, answered from your connected database.

  • Agent mode, with approval

    Copilot can work through an unfamiliar schema for you, and asks before it acts.

Why the editor

Your whole PostgreSQL workflow, in the editor you already use

  • Stop switching windows

    Query and manage PostgreSQL in the same place you write the code that uses it.

  • Stop looking up column names

    Completions come from the database you're connected to, not from memory or another tab.

  • AI that knows your data, and asks first

    @pgsql answers from your schema. Agent mode does the legwork and waits for your approval.

Hands-on

Build a research agent
backed by PostgreSQL on Azure

Go beyond queries and build a working agent: PostgreSQL as the vector store, a Microsoft Foundry agent as the brain, and real Washington State case law as the data. You need an Azure subscription to follow along.

  1. 01

    Step 1: Set up your environment

    Clone the repo, create a Python virtual environment, and add your keys to .env.

    Terminal
    $ git clone https://github.com/Azure-Samples/postgres-agents$ cd postgres-agents$ pip install -r requirements.txt
  2. 02

    Step 2: Enable the extensions

    Allow-list azure_ai and vector on your Azure Database for PostgreSQL server, then create them.

    SQL
    CREATE EXTENSION IF NOT EXISTS azure_ai;CREATE EXTENSION IF NOT EXISTS vector;
  3. 03

    Step 3: Load data and generate embeddings

    Create the cases table and embed the case opinions with Azure OpenAI. About 3–5 minutes.

    Terminal
    $ cd load_data$ python main.py$ cd ..
  4. 04

    Step 4: Give your agent a Postgres tool

    vector_search_cases in legal_agent_tools.py runs a pgvector similarity search the agent can call.

    legal_agent_tools.py
    def vector_search_cases(query)
  5. 05

    Step 5: Create and run the agent

    Initialize the agent in your Microsoft Foundry project with gpt-4o-mini, and answer a real legal question end to end.

    Terminal
    $ python src/simple_postgres_and_ai_agent.py
  6. 06

    Step 6: Test and iterate

    Ask follow-up questions in the Microsoft Foundry playground and trace each step.

    PlanCall toolAnswer
